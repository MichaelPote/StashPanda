# StashPanda: what is left to build

Status as of 2026-10-25 (version 0.6.0). Milestones 0, 1 and 2 are done, and so is all of
milestone 3 apart from the SSH fallback below. This file lists only work that is still open.
Finished work is in the Git history, and [architecture.md](architecture.md) describes how the app
works now, with the pitfalls found on the way.

Each item names the files it touches, so it can be picked up cold.

## Packaging and release

- [ ] **App icon.** The source is `assets/app_icon.psd` (2048 × 2048), which Git ignores. Export
      it as `assets/app_icon.png` with transparent corners, since the flattened Photoshop image
      fills them with blue, then run `npm run icons` (`tauri icon`) to write every size into
      `src-tauri/icons/`. `bundle.icon` in `src-tauri/tauri.conf.json` already names those files.
      Delete the `android/` and `ios/` folders it also creates.
- [ ] **First run of GitHub Actions.** `.github/workflows/build.yml` tests on Ubuntu 22.04, then
      builds `.deb`, `.rpm` and AppImage there and the NSIS installer on `windows-latest`. It has
      never run, because `main` has not been pushed since 2026-10-16.
- [ ] **Release build check.** `[profile.release]` in `src-tauri/Cargo.toml` sets `lto = true`,
      `codegen-units = 1`, `panic = "abort"` and `strip = true`. Confirm the release binary starts
      on Linux and Windows, and measure how long it takes to start.
- [ ] **Check that `bindings.ts` is up to date in CI.** `src/lib/bindings.ts` is regenerated by
      `cargo test export_bindings` and committed. Add a step to the workflow that regenerates it
      and fails when `git diff` is not empty.
- [ ] **macOS build.** The code is ready (see "Platforms and builds" in architecture.md) and the macOS job is
      in the workflow's matrix, commented out. It needs a Mac or a macOS runner, and an Apple
      Developer ID certificate with notarization, without which Gatekeeper refuses the app.
- [ ] **Unused `.woff` fonts.** The `@fontsource` stylesheets list a `.woff` copy of every `.woff2`
      file, so about 0.9 MB of the 1.7 MB of bundled fonts is never loaded: WebView2 and WebKitGTK
      both read `.woff2`. Leave the `.woff` files out in a build step if the installer size
      matters.

## SSH

- [ ] **SSH fallback through OpenSSH** (tier 2, `transport/ssh_exec.rs`, not written). A
      long-lived `ssh -T host sh` helper with sentinel framing, built only if a real host needs
      `ProxyCommand`, `ProxyJump`, GSSAPI, certificates, or an algorithm `russh` cannot
      negotiate. Today `transport/ssh_pool.rs` refuses `ProxyCommand` and `ProxyJump` with
      `SshUnsupportedFeature`.
- [ ] **Native `ProxyJump`**, by opening a second `russh` connection through a `direct-tcpip`
      channel of the first. An alternative to tier 2 for the jump-host case.
- [ ] **Writing PPK files.** `keys::export_private` writes OpenSSH and PKCS#8 only: the `ssh-key`
      crate reads PPK but cannot write it. Left until a tool that still needs PPK turns up.
- [ ] **A `GIT_ASKPASS` helper.** Every command runs with `GIT_TERMINAL_PROMPT=0`, so a remote
      that asks for a password or a passphrase fails, and `networkFailureText` in
      `lib/repoActions.ts` explains why. A helper would let the app ask instead.

## Git behaviour

- [ ] With a custom fetch mapping, Delete Remote Branch's messages show the remote-tracking
      branch's name, although the right branch is deleted.
- [ ] Windows `git.exe` run from the Linux build through WSL interop gets `setsid` on the Linux
      side, which does not reach the Windows process tree, so Stop cannot end it cleanly.
- [ ] A fetch stopped on Windows at the moment it writes refs can leave a `.lock` file under
      `.git/refs`, because `taskkill /F` gives Git no chance to clean up.
- [ ] **Not confirmed, so not fixed** (from the review of every Git command, 2026-10-15): a stalled
      automatic fetch blocking other writes, and the Pull dialog's default when the upstream
      branch is gone.

Decisions to revisit:

- File names that are not valid UTF-8 are refused by every action, with a reason. Supporting
  them means carrying paths as raw bytes through Rust, the IPC layer and the frontend.
- Blame refuses when `blame.ignoreRevsFile` names a missing file, since Git offers no override;
  the message names the setting as the cause.
- Taking a side on a submodule conflict leaves the submodule's own checkout where it is, as Git
  does, so it shows as modified until it is updated.
- `repo_add` stores `resolvedTransport` and `repo_open` updates it. A repository whose `Auto`
  resolution changes between opens (a distro renamed, Windows Git installed) silently gets a new
  `RepoEntry.key`, and with it an empty cache and no remembered UI state. Decide whether the key
  should follow the path only.
- `keys_convert` names OpenSSH output after the file without its extension, so `foo.ppk` becomes
  `foo` beside it; a file with no extension is refused unless `overwrite` is set. Confirm this is
  the naming wanted.

## Performance

- [ ] **Graph pages carry edges nobody sees.** git.git's graph is 282 lanes wide, and a page from
      the middle of it is 2.4 MB of JSON (43,520 edges) for lanes the graph column clips anyway.
      That, not the backend, is the likely cost of scrolling it. `graph_rows` in `ipc/graph.rs`
      could leave out edges beyond the column's width.
- [ ] Discard runs a full `git status`, and stage, discard and commit each run a few more Git
      commands than they did before the command review. Measure them on a large repository.

## Settings

  nothing, and the Settings dialog leaves them out (`components/settings/sections.ts`). Delete

  heading.
- Add Repository: switching the connection to SSH does not fill Host and User from a

## Code rough edges

- `CatFile::read` (`git/catfile.rs`) breaks when its future is dropped part way through a request:
  the answer stays in the helper's output, and the next request reads it as its own.
  `get_conflict_file` avoids this by never cancelling a read (`tokio::join!`, not `try_join!`);
  any other caller that cancels a read could hit it.
- `GitError::CommandFailed { argv }` is an empty `vec![]` in eight places in the query modules,
  because the command line is only rendered inside `GitClient::exec`. Pass it through, or drop the
  field.
- `WslTransport::probe` treats exit code 255 or -1 as "distro missing" only when the message
  matches, and `wsl.exe`'s error text varies by version and language.
- `graph_rows` caps `count` at 1000 a call; the frontend asks for 200. The cap is not in the
  generated bindings' documentation.
- `perRepo[key].hiddenRefs` keeps the names of branches that were hidden and later deleted. A
  missing ref hides nothing, but the list is never pruned.
- The side-by-side diff sizes each horizontal scroll range from a character count (a tab counts as
  8 columns), so lines with unusually wide or narrow characters can leave it slightly long or
  short.
- `get_modified_times` over SSH reports whole seconds, while Local and WSL report milliseconds, so
  files changed within the same second can sort in either order.
